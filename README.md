# Blockchain de Entregas

Projeto simples em Node.js que demonstra uma blockchain para registrar entregas e verificar se os blocos foram alterados.

## Requisito

- Node.js instalado.

## Como executar

No terminal, dentro da pasta do projeto, execute:

```powershell
node principal.js
```

O programa exibirá a cadeia de blocos, validará a blockchain e demonstrará a detecção de uma adulteração.

## Como executar os testes

```powershell
node teste.js
```

Se tudo estiver correto, será exibida a mensagem `Todos os testes passaram.`

## Arquivos principais

- `principal.js`: executa a demonstração do projeto.
- `blockchain.js`: implementa a cadeia de blocos.
- `bloco.js`: implementa cada bloco e seu hash.
- `teste.js`: contém os testes automatizados.
